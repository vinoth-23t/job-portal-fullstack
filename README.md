# Role-Based Job Portal Application

A full-stack Job Portal web application built using React.js, Flask, and MySQL.

---

## Features

### Candidate
- Register & Login
- View Jobs
- Apply for Jobs

### Recruiter
- Add Jobs
- Delete Jobs
- Manage Job Listings

### Admin
- Full Dashboard Access
- Manage Users & Jobs

---

## Tech Stack

### Frontend
- React.js
- CSS
- Axios
- React Router DOM

### Backend
- Flask
- REST APIs
- Flask-CORS

### Database
- MySQL

---

## APIs Used

- Internal REST APIs
- External Jobs API (Remotive API)
